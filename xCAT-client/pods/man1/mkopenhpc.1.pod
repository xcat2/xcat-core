=head1 NAME

mkopenhpc - Prepare an xCAT compute image for OpenHPC Slurm

=head1 SYNOPSIS

B<mkopenhpc> B<--image> I<name> B<--controller> I<host[:port]> [B<--nodes> I<noderange>] [B<--check>]

B<mkopenhpc> B<--help>

=head1 DESCRIPTION

Run B<mkopenhpc> as root on the xCAT management node. It attaches a file
synchronization list and the B<configopenhpc> postbootscript to an existing
AlmaLinux 10 or Rocky Linux 10 osimage on x86_64 or aarch64. Stateful images
install OpenHPC 4 compute packages from the configured DNF repositories at
first boot. Stateless images install those packages during B<genimage>.
Compute nodes start MUNGE and configless Slurm after receiving the controller's
key through xCAT's SSH-based file synchronization.

openEuler 24.03 LTS SP2 and SP4 support is experimental on x86_64 for both
image modes. Use the openEuler OpenHPC 4 repository and the dependency
repositories for the matching openEuler service pack, including C<debuginfo>
for C<ohpc-base-compute>. Build stateless openEuler
images on an openEuler host of the same architecture and service pack so the
image uses the native RPM database format. On a separate build host, make the
xCAT netboot postscripts from the management node available in the xCAT
installation tree before running B<genimage>.

Set up the Slurm controller and its compute node definitions first. The
controller must have C<SlurmctldParameters=enable_configless> in C<slurm.conf>.
Place its MUNGE key at C</etc/munge/munge.key> on the management node with
permissions C<0400> or C<0600>. Keep the xCAT B<syncfiles> postscript enabled.
xCAT transfers the key through its file synchronization mechanism. Use the
image only for nodes that should share this key.

For stateful images, configure trusted OpenHPC 4 and distribution dependency
repositories in the installed OS. On AlmaLinux and Rocky Linux, enable EPEL and
CRB. The OpenHPC 4.x installation guides cover the release RPM and repository
keys (https://github.com/openhpc/ohpc/wiki/4.x).

For stateless images, configure the OpenHPC 4 and OS dependency build
repositories in the osimage's C<otherpkgdir>. Import the signing
keys for the base OS and those repositories on the node that runs
B<genimage>. B<mkopenhpc> appends a managed package list and
postinstall script and enables C<gpgcheck> when unset. The postinstall
script removes the key generated by the MUNGE package. The
node-qualified synclist transfers the controller key at boot and keeps it
out of the root image.

=head1 OPTIONS

=over

=item B<--image> I<name>

Existing xCAT osimage with C<osvers=alma10> or C<osvers=rocky10>, with an
optional minor version, C<osarch=x86_64> or C<osarch=aarch64>, and
C<provmethod=install> or C<provmethod=netboot>.
Experimental openEuler images use C<osvers=openeuler24.03sp2> or
C<osvers=openeuler24.03sp4> and C<osarch=x86_64>.

=item B<--controller> I<host[:port]>

Reachable host name or IPv4 address of the Slurm controller. Slurm uses port
6817 unless a port is given.

=item B<--check>

Check the osimage and management-node prerequisites without applying the
configuration.

=item B<--nodes> I<noderange>

Limit credential synchronization to this node or group range. Required for
netboot images. Quote ranges with brackets.

=back

=head1 EXAMPLES

Prepare an image, then set the boot state of the intended compute nodes.

  mkopenhpc --image alma10.2-x86_64-install-compute --controller slurmctl
  nodeset 'c[01-02]' osimage=alma10.2-x86_64-install-compute

Boot the nodes through the normal xCAT provisioning process. Verify the
registered nodes with C<sinfo> and run a job across them from the controller.

For a netboot image with C<otherpkgdir> and the signing keys already
configured, build and pack the image before assigning it to nodes.
C<--nosyncfiles> also keeps any site synclists out of the packed image.

  mkopenhpc --image rocky10.2-x86_64-netboot-compute --controller slurmctl --nodes 'c[01-02]'
  genimage rocky10.2-x86_64-netboot-compute
  packimage --nosyncfiles rocky10.2-x86_64-netboot-compute
  nodeset 'c[01-02]' osimage=rocky10.2-x86_64-netboot-compute

For nodes already provisioned with this image, synchronize the files and
apply the postbootscript for their provisioning mode.

  updatenode 'c[01-02]' -F
  updatenode 'c[01-02]' -P configopenhpc

For stateless nodes use C<updatenode 'c[01-02]' -P "configopenhpc netboot">.

The postbootscript manages the Slurm service's C<SLURMD_OPTIONS> using a
dedicated environment file and systemd drop-in. Drain active Slurm nodes
before changing the controller or MUNGE key and reapplying the postbootscript.
